# Portofolio Haytsam Suchandra Wiranegara

Website portofolio bertema satelit geospasial, dibuat dengan HTML, CSS, dan JavaScript murni (tanpa framework).

## Fitur
- Satelit yang mengorbit planet (Canvas) dan bintang latar yang berkelip
- Konten dinamis dari satu objek `DATA` di `script.js`
- Filter proyek, jendela detail, timeline, keahlian, form kontak
- Responsif dan mendukung `prefers-reduced-motion`

## Struktur
```
index.html   Struktur halaman
style.css    Tampilan
script.js    Animasi dan konten (edit objek DATA di bagian atas)
```

## Menjalankan
Buka `index.html` di browser.

## Menayangkan dengan GitHub Pages
1. Unggah ketiga file ke repositori GitHub (di root).
2. Buka Settings, lalu Pages.
3. Pada Source pilih "Deploy from a branch", branch `main`, folder `/ (root)`, lalu Save.
4. Situs aktif di `https://USERNAME.github.io/NAMA-REPO/`.

## Mengubah isi
Ganti bagian bertanda `CONTOH` pada objek `DATA` di `script.js`: proyek, timeline, keahlian, dan kontak.
